# 🌱 BioAgro Brasil

## 📋 Sobre o Projeto

**BioAgro Brasil** é um site institucional e blog moderno desenvolvido para o **Concurso Agrinho 2026**, com o tema **"Benefícios da Bioeconomia para o Agronegócio"**.

O projeto apresenta de forma clara e profissional os conceitos, benefícios, tendências e desafios da bioeconomia aplicada ao campo brasileiro, com ênfase em economia circular, agricultura digital, créditos de carbono e inovação sustentável.

---

## ✨ Funcionalidades

- **Design moderno e profissional** em estilo Magazine Digital
- **100% Responsivo** (Mobile First) – excelente experiência em celular, tablet e desktop
- **Menu Hambúrguer** funcional na versão mobile
- **Dark Mode / Light Mode** com persistência no `localStorage`
- **Feed de Notícias dinâmico** com 8 artigos reais (renderizado via JavaScript)
- **Filtro por categoria** nas notícias (Todos, Tecnologia, Sustentabilidade, Mercado, Políticas)
- **Animações suaves** ao rolar a página (Intersection Observer)
- **Scroll suave** entre seções
- **Formulário de Newsletter** com validação completa
- **Tabela interativa** de Economia Circular

---

## 🛠️ Tecnologias Utilizadas

## 📖 Base de Conteúdo

Todo o conteúdo do site foi desenvolvido com base no documento **"Benefícios da Bioeconomia para o Agronegócio.pdf"**, incluindo:

- Benefícios Econômicos, Ambientais e Sociais
- Economia Circular no Campo (com exemplos práticos)
- Agricultura Digital e Bioeconomia
- Créditos de Carbono e Serviços Ambientais
- Tendências Futuras (Agricultura Regenerativa, Biofábricas, etc.)
- Desafios da Bioeconomia Agrícola
- Conclusão estratégica
